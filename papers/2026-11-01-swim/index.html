SWIM: Learning What Matters from Behaviors for JEPA World Models

Behavior-prediction gates shape the distance learned by a visual latent world model.

THE TAKEAWAY

Use behavior to weight representation distances, while testing policy-dependent shortcuts.

KEEP IN MIND

Training requires simulator states and logged actions. Default-setting average gains are about one percentage point; no physical-robot transfer is demonstrated.

The transcript.

A robot planner searches for actions that move its imagined future toward a goal. If distance in the model's representation emphasizes irrelevant visual differences, that search can fail even when prediction looks plausible. A joint-embedding predictive architecture learns to predict future feature vectors rather than reconstruct pixels. This paper asks how to make distances between those vectors reflect the physical changes that actually matter for behavior.

Simulator states can supervise the representation, but equal weighting is not automatically neutral. Repeated encodings of the same variable can count one physical change several times. Irrelevant coordinates can dominate useful ones. Hand-selecting state features is brittle. The proposed alternative learns one importance weight per state coordinate from recorded behavior, without reward labels. Its assumption is that variables useful for explaining actions are also useful for planning; that is plausible, not guaranteed.

The experiments use five visual manipulation tasks from OGBench, a benchmark of offline goal-reaching environments. These include moving one to four cubes and interacting with a scene. The main comparison adds learned weights to the same state-supervised latent world model used by a uniform-weight baseline called SCALE-All. Both receive the same offline trajectories and planning protocol. This isolates weighting more cleanly than comparing unrelated pretrained models. Physical robot deployment is not demonstrated.

First, a small neural network receives the current simulator state and a weighted difference between current and later states. It predicts the action chunk recorded in that trajectory. Trainable sigmoid gates control each displacement coordinate. The loss rewards accurate action prediction, favors the true future over mismatched futures, and penalizes large gate weights. Then the gates are frozen. A second training stage makes distances between image features correlate with distances between weighted states, while retaining future-feature prediction and a non-collapse regularizer. At deployment only images, latent dynamics and action search remain. The state-weighting network is discarded.

The headline table tunes the sparsity weight separately for each task. Under that condition, scene success reaches thirty-nine point four percent, versus thirty-three point four for uniform weights, across five training seeds. That is a six-point gain, not the fixed-setting average gain. With default settings averaged across tasks and both planners, the reported improvements are about one percentage point. A pretrained visual-feature baseline remains better on the three-cube task. These are simulation results from the authors, not a general ranking of world models.

The reusable idea is to shape a representation's distance using what predicts behavior, rather than reconstructing everything equally. For sensing representations, that suggests a hypothesis, not evidence of transfer: weigh changes by their relevance to a downstream decision. The method needs privileged state and logged actions during training. Learned gates can reflect behavior-policy correlations, not causal importance. Mismatched futures are not guaranteed to be impossible alternatives. There is no proof that a global gate vector will remain appropriate when tasks or the policy change.
