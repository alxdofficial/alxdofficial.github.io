1. Keep learning without a growing prompt

A language model can learn new tasks by changing its weights, but those changes can erase earlier skills. Alternatively, it can carry instructions and examples in its prompt, but that context has limited space. This preprint combines the two: improve a compact external set of instructions during training, then teach those improvements into the model’s weights. At deployment, only the updated weights are needed. The paper calls this system HERD. Its evidence comes from one four-billion-parameter Qwen model learning twenty-five supervised tasks in sequence.

2. Why two kinds of retention matter

Keeping the latest checkpoint close is not enough. Many small updates can gradually move the model far from its original general abilities. HERD therefore compares the student with two frozen reference models: the previous checkpoint on retained task probes, and the original base model on general probes. It measures differences between their next-token probability distributions. These are finite sampled checks, not a guarantee that every earlier behavior survives. The distinction is useful: retaining yesterday’s tasks and retaining the original model’s broad abilities are separate objectives.

3. Build a bounded training aid

The external training aid stores reusable instruction snippets and examples the current system still finds difficult. On a bounded window of verified training examples, the base model proposes a revised instruction after seeing selected mistakes. The revision is accepted only if it improves the previous checkpoint’s probability of the correct answers and fits the token budget. The hardest remaining examples become probes for later retention checks. Importantly, this memory is not used as a conventional replay batch of supervised targets. It chooses where later drift should be measured.

4. Move the guidance into weights

A frozen teacher receives the selected instruction, the prompt, and the verified answer repeated in its context. A student receives the bare prompt. At each position of the verified answer, training makes the student’s full vocabulary probabilities match the teacher’s. Only newly attached low-rank weight updates are trained; the checkpoint itself stays frozen during that stage. This is low-rank adaptation. Penalties increase when either reference-model drift exceeds its budget. After thirty-two updates, the adapter is merged into the weights. The next stage starts from those merged weights with a fresh adapter.

5. Matched results, with limits

On the twenty-five-task stream, the final average normalized task score is point seven zero six, versus point six nine nine for uniform replay. That difference’s confidence interval includes zero, so it is not a clear win over replay on final score. Average forgetting is point zero one zero, versus point zero two zero for replay. On separate general tests, HERD loses six point three percentage points from its starting score; sequential low-rank adaptation loses twenty-four points. These are author-reported three-seed results. Task scores combine several metrics, not one uniform accuracy measure.

6. Reusable idea, not solved lifelong learning

The strongest reusable idea is to distill helpful training-time context while guarding both recent and original behavior. Removing the base-model guard increases the general-test drop from six point three to fifteen point eight points, but that ablation uses only one seed. The system still needs verified answers, known task boundaries, and a finite probe set. It was tested on one base model and one task stream. Its context-based comparisons also have strict memory ceilings. This is promising controlled evidence for a training recipe, not proof of unrestricted online learning or zero forgetting.
