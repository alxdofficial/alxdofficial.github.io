Cortex: Consolidating Context into Parametric Memory

Can useful context survive after the prompt disappears? A careful look at learning new behavior while preserving the old.

THE TAKEAWAY

Retest older examples after every update, even when the original weights stay frozen.

KEEP IN MIND

The transcript.

1. Problem, importance, and difficulty

Today's must-read is Cortex. A model can use a manual in its prompt, then lose the benefit when it disappears. Cortex asks whether useful context can become lasting model behavior. Learn new behavior while preserving what already works.

2. Demonstrated applications

The authors test new Python APIs, factual edits, agent experience, behavioral steering, and answering restrictions. These are text-based experiments. The API test covers fifteen packages and one hundred fifty executable-test problems. A multimodal backbone appears, but sensor or visual-memory transfer is not demonstrated.

3. Prior approaches and narrow novelty

Earlier work distills context, edits factual associations, or adds adapters. Cortex combines anticipated-use questions, feed-forward-only writes, and consolidation-versus-retention evaluation. Its novelty is this particular combination. The results do not establish universal superiority over retrieval.

4. Method

The frozen pre-update model generates questions anticipating uses of the new context. It answers with the context available. A context-free student matches the teacher's output probabilities and intermediate representations. Only new feed-forward parameters change. The synaptic version learns low-rank weight updates; the structural version adds nonlinear channels. Earlier weights stay frozen. Sequential learning replays stored questions, regenerating their answers from the pre-update model. At inference, learned changes operate inside the model without source-document lookup.

5. Results

After fifty factual edits on the Qwen two point five fourteen billion instruction model, Structural Cortex recovers eighty-eight point nine percent of the context-induced gain, versus twenty-eight point five for ROME. These matched results average three training runs. Consolidation rate measures recovered benefit, not raw accuracy. Retention is ninety-nine point eight percent of the original aggregate score on locality, MMLU, SimpleQA, and GSM8K. Structural adds roughly seven hundred forty thousand parameters per edit in this setup.

6. Comments, limitations, and reusable idea

Frozen weights do not guarantee stable behavior. Replay keeps average original-and-rephrased accuracy above ninety-six percent for the same first twenty-five facts after twenty-five further edits; without replay, Structural reaches forty point five percent. But replay also changes the optimization budget. This is one fixed sequence of fifty compatible facts, not indefinite lifelong learning. For frozen-memory classifiers, retest older examples after each update, even when only surrounding components change.
