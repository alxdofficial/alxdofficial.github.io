Latent Compaction with Test-Time Training

Compress a document’s attention cache for questions that have not been asked yet.

READ / COMPLETE NARRATION

The transcript.

1. Problem, importance, and difficulty

Latent Compaction asks whether a language model can preserve a long document in a smaller attention cache. Tomorrow's question may need a detail that looks unimportant today. Simply deleting entries or summarizing text can erase that detail. The goal is reusable memory for unseen questions.

2. Demonstrated and potential applications

The authors test synthetic retrieval, exact phonebook lookup, and natural-document understanding. Repeated queries about a fixed reference document could share one prepared cache. Streaming personal memory, multimodal sensors, and neuromorphic deployment remain untested.

3. Prior approaches and narrow novelty

Earlier methods already select important cache entries, train compact memories, or match attention behavior. It combines importance-and-diversity initialization, fitting that protects selected entries, and a final stage refining everything. Novelty lies in this specific recipe.

4. Method

The language model’s weights stay frozen. What changes are document-specific keys, values, and scalar attention biases. Three quarters of the compact budget starts with important original entries. The rest mixes high-attention anchors with keys chosen for diversity. Stage one freezes the important entries and fits the other slots to the full cache’s attention outputs and log-normalizers. Matching the normalizers helps compressed memory compete correctly with newly arriving tokens. Stage two updates every compact slot, matching the full-cache model’s output probabilities and preferred next tokens. Both stages use generic document prompts. Downstream questions stay hidden, and the finished cache is fixed during reuse.

5. Results

With Qwen three, one-point-seven billion parameters, at sixteen-times compression, Phonebook Lookup averaged eighty point six seven percent accuracy across three document lengths. Removing stage one reduced that to thirteen point nine two percent. Removing stage two scored seventy point six seven percent. These ablations show that both stages matter. They are author-reported results, without independent replication here.

6. Comments, limitations, and reusable idea

Preparation is expensive: four hundred eighty teacher rollouts, one thousand fitting updates per layer, then one thousand joint updates per document. And sixteen-times compression counts logical key-value pairs, not measured physical memory savings or speed. The reusable idea is to preserve both what a memory returns and its attention strength. Test exact recall and preparation cost together. This preprint does not establish an efficient production system.
