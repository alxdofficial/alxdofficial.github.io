MJev-Spatial: System One Spatial Intelligence via Native Attention Matching

M Jev Spatial studies a simple mismatch in visual language models. A question may only need a choice, a number, or a point, yet the model generates a sentence and another program parses it. That adds work to an already structured task. This paper replaces answer generation with direct candidate selection. A choice takes one decision. A number can take two decisions, while pointing takes three decisions with new image crops. So one forward pass means one classification step, not necessarily one complete prediction.

The intended use is fast spatial judgment: selecting a relation, estimating a distance, or locating where an object belongs. The pointing example shows a coarse region becoming a smaller crop, then a final location. Possible applications include robot perception and visual assistance, but this is a benchmark study, not a deployed robot controller. Numerical answers also have explicit contracts. Distances use meters, angles use degrees, and counts have a fixed range. Ambiguous units or unsupported quantities are rejected rather than silently converted into an answer.

Spatial language models from twenty twenty four and twenty twenty five already learned relations and coordinate answers from spatial supervision. More recent decision models, including Jev and Visual Jev, already scored candidates instead of writing unrestricted text. Discretizing a continuous number and zooming into an image are also established ideas. The contribution here is a shared spatial decision interface that reuses pretrained attention projections. It handles answer options, numerical intervals, and image regions with the same scorer, rather than introducing a separate prediction head for each output type.

The backbone is Qwen three point five, four billion parameters. Each candidate is written alongside the question and images, followed by an end marker. A final decision marker sees the complete candidate set. The model turns that decision state into a query and each candidate state into a key, using pretrained attention weights. Similarities become candidate probabilities. Training updates the retained language parameters on twelve point three million converted spatial questions; the vision encoder stays frozen. For pointing, selected crops supply fresh local detail before the next decision.

Across twelve spatial benchmarks, the final model averages sixty five point six four percent, versus fifty four point eight for its unmodified base. It leads seven benchmarks among eight tested models. On the same B two hundred graphics processor at batch size one, mean query latency is one hundred sixty point six milliseconds, versus eight hundred ninety four point one. Timing includes image input, preprocessing, inference, and decoding, but excludes loading. These final comparisons combine the new interface with extensive supervised training; they do not isolate architecture alone.

The controlled readout pilot is more mixed. Native attention matching improves one localization benchmark but trails a linear head on another. Training data checks remove exact and near-duplicate images, without proving independence between related scenes. Confidence intervals are not reported for the headline results. Multiple-point prediction also requires extra tree exploration. Still, public code and model weights are available. The useful takeaway is that specialized decision interfaces can improve the measured speed and accuracy of structured spatial tasks. A fair next test would match training data against an equally adapted generative model.
