READ / COMPLETE NARRATION

The transcript.

Instead of giving each EEG study an unrelated label vocabulary, this paper describes tasks in ordinary language. A sentence encoder maps instructions, stimuli, and response requirements into a shared numerical space. An EEG encoder learns to place a recording near the matching description. At inference, it chooses the closest description from a supplied candidate list. That is calibration-free prediction for the target condition, not unrestricted mind reading. A single channel here means the measured voltage difference between two real electrodes, one toward the front and one toward the back of the scalp.

The waveform-only model summarizes eight seconds of EEG using convolutions and temporal averages. The stronger reserved-test model adds three time-frequency views of that same channel, then combines their features. It has about 365 thousand inference parameters. Training combines within-study task classification with bidirectional alignment to fixed text descriptions. The training mixture called Bridge3 mostly preserves an earlier multi-task mixture and assigns five percent of sampling to three added datasets. A competing package also adapts the text space, but its gains during development do not hold on the reserved evaluation.

The reserved evaluation contains ten task classes from seven dataset identifiers, with 87,058 nonoverlapping eight-second windows. Source-level participant counts sum to 290, but cross-source identities are not verified as unique. The best observed configuration reaches 30.13 percent balanced accuracy, against ten percent chance. Balanced accuracy gives equal weight to each class and each participant within that class. Its participant-bootstrap interval is 28.28 to 32.11 percent, conditional on these sources and trained models. This is the highest observed result among nine fixed configurations, not an independently confirmed universal winner.

Three classes contribute almost seventy percent of that overall score. Go-or-no-go recognition alone contributes 9.72 percentage points, and its participants had supplied training recordings from other tasks. Removing the two known-participant classes from the averaging gives 21.75 percent recall while retaining all ten candidate labels. More importantly, the leading model gets only 50.34 percent when distinguishing thinking from meditation within one study, against fifty percent chance. Three driving conditions give 34.43 percent against 33.33 percent chance. These exploratory controls reveal how little the broad average establishes about cognitive specificity.

A separate developmental experiment tests person-specific calibration. With sixteen labeled eight-second examples per available class, accuracy reaches 34.47 percent using another participant’s examples, and 74.99 percent using the test participant’s examples. But those queries last sixty-four seconds, use an earlier model and a different benchmark, and share the same task recording as the same-person support. Exact sample overlap is excluded; session dependence is not. Only one training seed was tested, and support size changes the eligible query pool. These numbers cannot be compared directly with the reserved-test headline.

The strongest contribution is a useful interface plus an unusually explicit account of its confounds. Descriptions let heterogeneous studies share targets, but text similarity is not evidence of neural equivalence. Source recognition and participant context remain plausible shortcuts, and code is promised upon acceptance rather than already released. For multisensor systems, a speculative extension would combine semantic labels with strict unseen-person, unseen-device, and within-source tests, plus an unknown-class rejection option. This paper does not test that open-set setting. It is an October tenth preprint; its original figures are reused with attribution under Creative Commons.
