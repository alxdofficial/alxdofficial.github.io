RL-Guided Temporal Localization for Dual-Channel Retrieval in Long-Horizon Agent Memory

1 / Problem
TIDER tackles a familiar memory error: finding the right topic from the wrong day. Imagine asking about dinner after a family birthday. Semantic search can retrieve several other dinners and miss the one you meant. TIDER first predicts when the evidence should be. A separate temporal retrieval channel then adds memories from those dates, before the answer model sees its context. The key idea is to fix evidence selection, rather than hope the answer model repairs missing evidence.

2 / Applications
The demonstrated application is personal-memory question answering. LifeBench mixes synthetic chats, phone activity, travel, exercise records, and notes. LoCoMo tests long conversations. The authors evaluate separate LifeBench users and transfer the locator to LoCoMo without training on that dataset. Wearable event logs are a plausible extension, but this study does not process raw camera, audio, or motion signals, and it uses no real personal-memory corpus.

3 / Current state of the art
The closest comparisons are temporal memory trees, represented by TiMem, and answer-time temporal reasoning, represented by NeSTR. TIDER reruns these with the same answer-model identity and twenty retrieved memory units. Those units differ in size, so this is not a matched token budget. A September study already learned explicit time intervals for document reranking. TIDER's narrower contribution is reinforcement-trained, potentially multiple windows that generate additional candidates from personal histories. No matched comparison with that study is reported.

4 / Method
Here is the pipeline. An offline process extracts dated events, clusters nearby similar items, and summarizes them. For each question, a Qwen three, one point seven billion parameter locator reads thirty relevant timeline summaries. It predicts a temporal switch and date windows. When the switch is on, overlapping memories join the semantic candidates. Ranking adds an overlap bonus and discounts distant dates, while retaining a floor so distant relevant evidence can survive. The final twenty units go to a fixed answer model. Training begins with supervised examples, then compares eight sampled window outputs and favors the higher-reward choices. Rewards cover detecting temporal need, matching gold windows, retrieving gold evidence, and answering correctly. This uses explicit evidence and date supervision, not just answer rewards.

5 / Results and limitations
On four hundred eight LifeBench questions, TIDER scores sixty-one point five two percent, versus NeSTR's fifty-two point seven zero. On LoCoMo, it reaches seventy-eight point nine six, versus TiMem's seventy-five point three zero. The cleaner ablation holds memory construction fixed: temporal retrieval adds nine point three one percentage points. Reinforcement learning adds five point eight eight points over supervised training alone. But on LoCoMo's temporal questions, TIDER trails TiMem: seventy-one point six five versus seventy-seven point six three. Training takes about one hundred hours on two A one hundred GPUs for one reinforcement-learning run. The temporal pathway adds point four one seconds per query. The gains depend on synthetic histories with comparatively clean dates.

6 / Novelty and relevance
The practical lesson is that a growing memory needs temporal disambiguation as well as semantic similarity. TIDER learns how to read accumulated events; it does not demonstrate continuous online model learning or resistance to forgetting. For wearable-memory research, the useful next test would preserve source identifiers and uncertain event timestamps, then stress repeated activities, missing dates, and clock drift. Keep a semantic fallback when time is unreliable. This paper provides a concrete retrieval mechanism and controlled evidence to investigate that direction, rather than proof of wearable readiness.
